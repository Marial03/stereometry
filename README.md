# Стереометрия 3D • Построение сечений

Интерактивное веб-приложение (мини-CAD для уроков геометрии и подготовки к ЕГЭ), предназначенное для наглядного объяснения и самостоятельного построения сечений многогранников и тел вращения в 3D.
(HTML5 / CSS3 / JavaScript Canvas)

---

##  Основные возможности программы

### 1. Библиотека из 15 объёмных фигур и конструктор параметров
* **Призмы**: куб, прямоугольный параллелепипед, треугольная, четырёхугольная, шестиугольная и произвольная $n$-угольная призма ($n$ от 3 до 10).
* **Пирамиды и многогранники**: тетраэдр, четырёхугольная, шестиугольная и $n$-угольная пирамида, усечённая пирамида, правильный октаэдр.
* **Тела вращения**: цилиндр, конус, шар (сфера) — с автоматическим расчётом кривых в сечении (эллипс, круг, парабола, гипербола, треугольник, прямоугольник) и выводом формулы площади.
* **Гибкая настройка размеров**: ползунки высоты $H$, радиуса $R$, числа сторон $n$, наклона вершины и усечения.

### 2. Готовые шаблоны задач (16 учебных сценариев)
Задачи разбиты по классическим методам построения сечений:
* **Метод следов** (продление рёбер до пересечения с прямой в одной грани).
* **Параллельный перенос** (теоремы о пересечении параллельных граней третьей плоскостью и о прямой, параллельной плоскости).
* **Метод вспомогательных плоскостей (диагональных и проецирующих)**.
* **Сечения тел вращения** (конические сечения, осевые и параллельные сечения).

### 3. Два режима работы
1. **Объяснение (Пошагово)** — программа сама строит сечение от шага 0 до готового многоугольника. На каждом шаге:
   * подсвечивается активная грань, в которой ведётся построение;
   * выводится подробное текстовое объяснение с математической записью ($E_1 = MN \cap BC$) и ссылкой на аксиому/теорему;
   * поддерживается автопроигрывание (`▶ Авто`) и переход к любому шагу в списке.
2. **Тренажёр /  Чистая тетрадь (Строю сам)** — ученик или учитель строит сечение вручную с помощью интерактивных инструментов:
   * при включённом переключателе **«Проверять ошибки сразу»** программа подскажет, если точки или прямые скрещиваются и не лежат в одной плоскости;
   * при выключенном переключателе (**режим «Чистая тетрадь»**) можно свободно соединять любые точки, а затем нажать **«Проверить чертёж»** для сверки с эталонным сечением.

## Инструменты построения в режиме «Тренажёр / Тетрадь»

| Инструмент | Как работает |
| :--- | :--- |
| **Отрезок сечения** | Клик по 1-й точке $\to$ клик по 2-й точке в одной грани. Строит итоговый красный отрезок сечения. |
| **╱ Диагональ / Вспом. прямая** | Соединяет две точки вспомогательным синим отрезком (например, для проведения диагоналей основания). |
| **⤢ Продлить ребро / прямую** | Клик прямо по **ребру** фигуры мгновенно продлевает его в обе стороны. Либо клик по двум точкам проводит через них бесконечную прямую. |
| **▱ Продлить плоскость грани** | Клик по любой грани многогранника раскрывает полупрозрачный веер её бесконечной плоскости (для наглядного поиска следов вне фигуры). Повторный клик скрывает плоскость. |
| **◫ Вспом. плоскость (проекции)** | Клик по 1-й точке $\to$ клик по 2-й точке (например, $M$ и $N$). Программа опускает их ортогональные проекции на основание ($M_0, N_0$) и проводит через параллельные проектирующие прямые $MM_0 \parallel NN_0$ полупрозрачную вспомогательную плоскость $\beta$. |
| **✕ Точка пересечения прямых** | Клик по 1-й прямой/ребру $\to$ клик по 2-й прямой/ребру. Если прямые компланарны, на их пересечении создаётся новая точка (след) и автоматически дотягиваются пунктирные продолжения. |
| **∥ Параллельный перенос (3 шага)** | **Шаг 1**: клик по прямой-образцу $\to$ **Шаг 2**: клик по точке, через которую строим $\to$ **Шаг 3**: клик прямо по **грани (плоскости)**, в которой должна пройти параллельная прямая. |
| **Двигать M, N, K** | Перетаскивание исходных точек $M, N, K$ вдоль рёбер (с магнитной привязкой к серединам $1:1$, третям $1:2$ и четвертям). |
| **Ластик** | Удаляет ошибочно проведённые линии построения или штрихи маркера. |

## Управление видом, камерой и чистотой экрана

* **Мышь и клавиатура**:
  * **ЛКМ + перетаскивание** — вращение 3D-фигуры со всех сторон.
  * **Колёсико мыши** — приближение / отдаление (зум).
  * **ПКМ + перетаскивание** (или `Shift + ЛКМ`) — сдвиг (панорамирование) чертежа.
  * **Короткий клик ПКМ** или клавиша **`Esc`** — мгновенный сброс выбранной первой точки или незавершённого шага инструмента.
  * **Стрелки `←` / `→`** — переключение шагов построения в режиме «Объяснение».
* **Настройка внешнего вида фигуры и сечения**:
  * Режимы фигуры: *Полупрозрачные грани + ГОСТ пунктир*, *Только каркас (рёбра)* или *Плотный корпус*.
  * Заливка сечения: *Классическая штриховка (как в учебнике)*, *Заливка цветом + штриховка*, *Полупрозрачный цвет* или *Только контур*.
  * Переключение проекции: *📐Учебник (Ортогональная)* / * Перспектива*.
  * Темы оформления: * Светлая (Тетрадь)* / * Тёмная (Доска)*.
* **Маркер учителя поверх чертежа (`🖍 Маркер`)**:
  * Позволяет рисовать от руки прямо поверх 3D-чертежа во время урока.
  * Кнопка **` Цвет ▾`** открывает и скрывает палитру цветов маркера.
  * Кнопка **` Ластик маркера`** стирает отдельные штрихи маркера, а **` Стереть всё`** очищает все рукописные пометки.
* **Кнопки освобождения места на экране**:
  * **` Вспом. плоскость: Видна / Скрыта`** — скрывает заливку вспомогательной проецирующей плоскости после того, как след найден, чтобы она не загромождала чертёж.
  * **` Доли точек: Видны / Скрыты`** — включает или убирает подписи отношений (`1:1`, `1:2`) рядом с точками на 3D-чертеже.
  * **` Подсказка мыши`** (и кнопка `✕` на плашке) — скрывает нижнюю памятку по клавишам.
  * **`Скрыть точки ▲`** — сворачивает блок координат точек $M, N, K$ в левой панели.
  * **` Широкий чертёж`** — временно скрывает обе боковые панели, разворачивая 3D-чертёж на весь экран.
* **Синхронное 2D-окно справа**:
  * Вкладка **«Само сечение 2D»** — показывает истинную плоскую форму полученного многоугольника сечения, его периметр и площадь $S$.
  * Вкладка **«Вынос грани 2D»** — выносит любую выбранную грань многогранника на плоский чертёж вместе с точками, следами и продолжениями рёбер.
* **Экспорт**: кнопки **« Скачать PNG»** и **« В буфер»** для мгновенной вставки чертежа в презентацию, конспект или онлайн-доску (Miro, Holst, Zoom).
